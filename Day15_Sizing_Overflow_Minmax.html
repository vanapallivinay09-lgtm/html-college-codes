1. Extrinsic vs Intrinsic Size

Extrinsic: You set size

width:200px height:100px

Intrinsic: Content sets size

Hi! I grow with text
Longer text makes me longer automatically - intrinsic!

2. Handling Overflow

When content bigger than box - what to do?

overflow: visible (default)
This is very long text that is bigger than 80px height so it spills out of box - visible!


overflow: hidden
This long text is hidden - you can't see extra part - hidden!
overflow: scroll
This has scroll bars always - even if not needed - scroll! This is very long text...
overflow: auto (BEST!)
Auto shows scroll ONLY when needed - auto! This is long...
overflow-x: scroll (horizontal)
This is a very long single line text that needs horizontal scroll - overflow-x!

3. Min & Max Sizes - Responsive Design

I won't go smaller than 100px or bigger than 400px. If I have too much text, I scroll because max-height:120px + overflow:auto

Interview Notes

  • Extrinsic: width/height you set
  • Intrinsic: width auto based on content (like span)
  • overflow: hidden = hide extra
  • overflow: auto = scroll if needed (use this 90% time)
  • overflow-x / overflow-y = horizontal / vertical separately
  • min-width / max-width = responsive - most important for mobile!
