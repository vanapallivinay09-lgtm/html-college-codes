Interview Notes

Syntax: @media screen and (max-width: 600px) { ... }

Media Types: screen, print, all

Media Features: width, height, orientation (portrait/landscape)

Logical: and = both, , (comma) = OR, not = opposite

Breakpoints: Mobile 480px, Tablet 768px, Desktop 1024px
