CSS Specificity and Cascade - Day 14

1. Cascade - Order matters

I am blue first, then red later - RED wins (last)

2. Specificity Points

Type (p) = 1 point

Class (.text) = 10 points - BLUE wins over black

ID (#myText) = 100 points - GREEN wins

Inline Style = 1000 points - PINK wins over ID!

3. Specificity Calculation

p.text = 1+10=11 - ORANGE

div p.text = 1+1+10=12 - PURPLE wins (more specific)

4. Importance - !important = 10000 points

I have ID green but class has !important RED - RED wins!

Even inline pink loses to !important RED!

Rule: Never use !important unless emergency!

5. Final Order (Low to High)

  1. Type (p, h1) - 1
  2. Class (.card) - 10
  3. Attribute [type="text"] - 10
  4. Pseudo-class (:hover) - 10
  5. ID (#logo) - 100
  6. Inline style="..." - 1000
  7. !important - 10000 - The Important Exception

6. Most Fundamental Concepts of CSS

Cascade: Last rule wins if same points

Specificity: More points wins

Inheritance: Child gets text styles from parent (you learnt yesterday)

These 3 = Most Fundamental Concepts!
