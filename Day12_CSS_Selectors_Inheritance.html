CSS Selectors & Inheritance - Day 12

1. Type Selector (p, h2)

This p is gray because p { color: gray }

Another p - also gray

2. Class Selector (.card) - Use 100 times!

I am card 1 - using .card
I am card 2 - same class
I have TWO classes: card + highlight

Button using class: Click Me

3. ID Selector (#main-title) - Use only once!

I have id="special" - red border because #special

Rule: id must be unique! Don't use same id twice

4. Inheritance - Most Fundamental!

I am parent - color blue

I am child p - I inherited blue? No, I am green because .parent p is more specific

I am span child - I inherited blue from parent!
Grandchild div - I inherited font-family Arial but NOT border

Priority Order (Interview!)

ID (#) > Class (.) > Type (p)
Inline style > ID > Class > Type
Example: #main-title will beat .card will beat p
